# BMuon: Budgeting Muon's Spectral Geometry for Structured Compressibility

Official repository for **BMuon**, an optimizer that modifies Muon's spectral steepest-descent geometry to improve the structured compressibility of Muon-trained Transformers.

**Authors:** Rida Assalouh, Tom Jacobs, Rebekka Burkholz, Yani Ioannou, Umut Şimşekli.
